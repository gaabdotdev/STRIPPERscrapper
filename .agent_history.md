# Histórico do agente — StripperScrapper

## 2026-06-09 — Captcha gate local (T-CAPTCHA)

- **Fase:** implementação
- **Decisão:** continuar
- **Sumário:** Faculdade passou a exibir captcha no Infnet. Implementado `runCaptchaGate` em `src/utils/captchaGate.mjs`: browser visível (forceHeaded), espera até 60s (`CAPTCHA_WAIT_MS`) por resolução manual/redirecionamento, grava `session.json`, fecha browser; `main.js` corre scrape subsequente em headless (salvo `--headed`). Ativo por defeito (`CAPTCHA_GATE=1`); desativar com `CAPTCHA_GATE=0` ou `--no-captcha-gate`. GitHub Actions ignorado conforme pedido do utilizador.
